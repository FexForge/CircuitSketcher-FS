# Assets

Statische Ressourcen der Anwendung (aktuell: Logo für den Über-Dialog).

- `logo.png` – Logo der Hilfe-/Über-Seite. Empfohlen: PNG mit transparentem
  Hintergrund, ca. 600–800 px breit (längliches Format), Anzeige erfolgt
  auf 360 px Breite. Wird in der EXE über `--add-data assets;assets` eingebettet.

Fehlt die Datei, läuft die Anwendung und der Über-Dialog problemlos ohne Logo.
